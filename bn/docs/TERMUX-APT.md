২০২৬-১১-১৪ তারিখে historical source tag-এর GitHub Release entry ও স্বাক্ষরিত
stable APT বিতরণ প্রত্যাহার করা হয়েছে। উৎস-প্রমাণের জন্য source tag রাখা হয়েছে।
প্রকাশ্য `/apt` bootstrap, key, index ও package path এখন HTTP 404 ফেরায়। আগে
থেকে ইনস্টল করা package অক্ষত, তবে stable APT থেকে Ternux update পাওয়া যায় না।

এখন pinned source installer-ই সমর্থিত install পথ; [প্রধান নির্দেশিকা](../README.md)
দেখুন। ২০২৬-১১-১৬ তারিখে stable APT bootstrap/key/index এবং RC signed index আবার
পরীক্ষা করে HTTP 404 পাওয়া গেছে। RC bootstrap ও signing key HTTP 200 দিলেও hosted
repository থেকে `pkg install ternux` করা যায় না। Signed repository প্রকাশিত হলে
RC-কে optional candidate testing-এর জন্য ব্যবহার করা যাবে। ২০২৬-১১-১৪-এর আগের
সিদ্ধান্ত—package distribution-কে ভবিষ্যৎ platform scope-এর সঙ্গে বেঁধে রাখা—owner
প্রত্যাহার করেছেন। বর্তমান source status ও release evidence
[প্রকল্পের পরিকল্পনায়](project/PROJECT-ROADMAP.html) আছে। APT ফেরানোর আগে
আলাদা feasibility সিদ্ধান্ত দরকার। [পরবর্তী সংস্করণের package distribution
assessment](next/APT-DISTRIBUTION-FEASIBILITY.html) দেখুন। নিরাপত্তা, recovery ও
operations gate পাস না হওয়া পর্যন্ত source installer-ই ব্যবহার করুন। বর্তমানে
কোনো APT install method উপলভ্য বা সমর্থিত নয়।

## আস্থার ছাপ

প্রকল্পের পেজ-হোস্ট থেকে কী নেওয়ার আগে নিচের পূর্ণ ওপেনপিজিপি প্রধান-চাবির
আস্থার ছাপ গিটহাবের উৎস-পৃষ্ঠার ছাপের সঙ্গে মিলিয়ে নিন। গিটহাব সংগ্রহস্থল ও
পেজে থাকা এপিটি সংগ্রহস্থল আলাদা ঠিকানায় চলে।

```text
E552 7F4D 5B83 037F F77B 65AE 5E89 4BBB 8116 8B1D
```

এটি আরএসএ ৪০৯৬ স্বাক্ষর-চাবি; তৈরি ২০২৬-১১-০৬, মেয়াদ শেষ ২০৩১-১১-০৫।
সুরক্ষিত ব্যক্তিগত চাবি গিটহাব অ্যাকশনের `apt-release` পরিবেশে রাখা আছে;
সংগ্রহস্থলে শুধু প্রকাশ্য চাবি দেওয়া হবে।

## পুরোনো স্থিতিশীল প্যাকেজের তথ্য

প্রত্যাহার করা স্থিতিশীল সংগ্রহস্থলে `ternux_2.0.0_all.deb` ছিল; এসএইচএ-২৫৬
`4ef03210c71e3d5671671e9a49fc83f6aebf7cdb5e5a28cb32db61d49e85c89f`। নিরীক্ষার
জন্য এগুলো রাখা হয়েছে; বর্তমানে নামানোর ঠিকানা হিসেবে ব্যবহার করা যাবে না।

## আরসি সংগ্রহস্থল

আরসি বসানোর নিচের নির্দেশগুলো পুরোনো। ২০২৬-১১-১৬ তারিখে প্রকাশিত বুটস্ট্র্যাপ
ও সূচি পরীক্ষা করে এইচটিটিপি ৪০৪ পাওয়া গেছে; তাই এগুলো দিয়ে কার্যকর প্যাকেজ
উৎস যোগ হবে না। স্থিতিশীল বা আরসি—কোনো প্রকাশিত উৎস থেকেই `pkg install ternux`
এখন প্যাকেজ বসাবে না। পরীক্ষামূলক সংগ্রহস্থল আবার প্রকাশিত হলে নির্দেশ ফেরানোর
আগে বুটস্ট্র্যাপের ঠিকানা ও স্বাক্ষরিত সূচি যাচাই করতে হবে।

আপাতত প্রকল্পের `main` শাখার উৎস ইনস্টলার ব্যবহার করুন। ওয়েবসাইট প্রকাশের সময়
শুধু চালু এবং স্বাক্ষর ও চেকসাম-যাচাইকৃত এপিটি সংগ্রহস্থল রাখা হয়।
