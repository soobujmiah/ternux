ভবিষ্যৎ কাজের নথির প্রবেশদ্বার এটি। এখানে থাকা বিষয়গুলো অনুসন্ধানধর্মী; এগুলো
release commitment, বর্তমান সমর্থিত সুবিধার তালিকা বা ব্যবহারযোগ্য package
channel-এর প্রমাণ নয়। প্রকল্পে বর্তমানে Debian, Ubuntu, Kali Linux এবং Alpine-এর
চারটি desktop setup রক্ষণাবেক্ষণ করা হয়। Termux package repository বর্তমানে
অপ্রাপ্য।

## পরিকল্পনার নথি

- [বাস্তবায়ন পরিকল্পনা](IMPLEMENTATION-ROADMAP.html): ধাপ, প্রমাণের শর্ত ও
  সিদ্ধান্তের পর্যায়।
- [স্থাপত্য ও প্রস্তাব](../NEXT-ARCHITECTURE.html): সম্ভাব্য উপাদান ও সীমা।
- [বিস্তারিত স্থাপত্য সূচি](architecture/README.html): manager, workspace,
  device bridge, security ও acceptance নকশা।
- [সুবিধার প্রস্তাব](../NEXT-PROPOSALS.html): feasibility ও owner review দরকার এমন ধারণা।
- [বিতরণ-যোগ্যতা](APT-DISTRIBUTION-FEASIBILITY.html): package channel নিয়ে
  বিবেচনা; ব্যবহারযোগ্য channel-এর দাবি নয়।
- [Manager API schema](https://github.com/soobujmiah/ternux/tree/main/docs/next/schemas):
  source test-এ ব্যবহৃত machine-readable contract।

পুরোনো release record-গুলো provenance ও তারিখযুক্ত প্রমাণের জন্য রাখা হয়েছে;
সেগুলো বর্তমান support নির্ধারণ করে না। [বর্তমান প্রকল্প পরিকল্পনা](../project/PROJECT-ROADMAP.html)
ও [সমর্থন-তালিকা](https://github.com/soobujmiah/ternux/blob/main/docs/audit/FEATURE-MATRIX.md) বর্তমান অবস্থা জানায়।
