## পরবর্তী সংস্করণের স্থাপত্যের সূচি

**অবস্থা: proposal ও implementation আংশিক।** কিছু manager ও Control Center
কাজ source-এ আছে, তবে এগুলো সম্পূর্ণ platform বা release নয়। ঐতিহাসিক source
archive ও version-specific guide কেবল আগের source-এর evidence হিসেবে রাখা হয়েছে;
GitHub Release entry সরানো হয়েছে এবং package repository অনুপলভ্য। কোনো নতুন
capability-কে shipped বলতে হলে তার নিজস্ব test ও release evidence লাগবে। বর্তমান
অবস্থা [project status](/docs/project/IMPLEMENTATION-STATUS.html) এবং
[historical release record](/docs/release/V2-RELEASE-REPORT.html)-এ আছে।
