প্রতিটি Ternux release-এর জন্য সেই নির্দিষ্ট সংস্করণের নির্দেশিকা ব্যবহার
করুন। পুরোনো release বসাতে বর্তমান `main` branch বা পরের installer ব্যবহার
করবেন না।

- [Ternux v1.4.0 — ঐতিহাসিক install guide](pages/v1.4.0-INSTALLATION.md):
  source tag `v1.4.0`, commit
  `3e6c07e2afcb5f1e65ecd57af19b0382a948835a`।
- [Ternux v2.0.1 — প্রকাশিত installation guide](pages/v2.0.1-INSTALLATION.md):
  tag, source commit, archive, checksum ও GitHub release page যাচাই হয়েছে.
- [v2 release audit reconciliation](V2-RELEASE-RECONCILIATION.md): release
  evidence, scope সিদ্ধান্ত, সীমাবদ্ধতা ও follow-up boundary-এর প্রতিবেদন।
- [Release guide template](../../../docs/release/templates/RELEASE-INSTALLATION-TEMPLATE.md):
  ভবিষ্যৎ release-এর জন্য ব্যবহার করুন এবং provenance ও recovery-এর সব তথ্য পূরণ করুন।

Root README বর্তমান `main` branch বর্ণনা করে; এটি version-specific guide-এর
বিকল্প নয়। Stable v2 APT repository প্রত্যাহৃত।
