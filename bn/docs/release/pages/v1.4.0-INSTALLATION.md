**প্রকাশনা:** v1.4.0<br>
**Tag:** `v1.4.0`<br>
**Tag commit:** `3e6c07e2afcb5f1e65ecd57af19b0382a948835a`<br>
**অবস্থা:** পুরোনো প্রকাশিত সংস্করণ; কোনো binary asset সংযুক্ত নেই।

এই নির্দেশিকা `v1.4.0` tag-এর source snapshot বসায়, বর্তমান `main` নয়।
২০২৬-১১-১৮ তারিখে GitHub থেকে tag archive নামিয়ে installer চালালে
`ternux installer v1.4.0` দেখিয়েছে। তখন পাওয়া archive-এর SHA-256:

```text
e3428805d0b9ba8c5875ee93b84fe38ff3eb16e32de9416e9bf1c2445e863eb6  v1.4.0.tar.gz
```

GitHub release-এ archive বা checksum আলাদা asset হিসেবে নেই। তাই checksum-টি
তখনকার codeload response-এর digest; publisher-signed artifact নয়। ব্যবহার
করার আগে উপরের tag commit মিলিয়ে নিন।

## প্রয়োজনীয়তা

- ARM64 Android; base install-এর জন্য অন্তত ৫ GB খালি storage এবং download/cache
  এর জন্য অতিরিক্ত জায়গা।
- F-Droid অথবা Termux-এর GitHub release থেকে Termux। Add-on একই উৎস থেকে বসান।
- অফিসিয়াল Termux:X11 বসিয়ে একবার খুলুন।
- Internet, `pkg`, `bash`, `tar` এবং `curl` অথবা `wget`।
- Termux:X11 APK বসানোর Android permission। Storage permission ঐচ্ছিক।

এই release ARM64 ও Debian PRoot desktop-এর জন্য। এটি root access বা kernel
container দেয় না।

## সঠিক v1.4.0 উৎস বসান

Termux-এ চালান:

```bash
pkg update -y
pkg install -y bash ca-certificates coreutils curl grep tar wget
work="$(mktemp -d)" || exit 1
archive="$work/v1.4.0.tar.gz"
url="https://codeload.github.com/soobujmiah/ternux/tar.gz/refs/tags/v1.4.0"
if ! curl -fL "$url" -o "$archive"; then
  wget -O "$archive" "$url" || exit 1
fi
printf '%s  %s\n' 'e3428805d0b9ba8c5875ee93b84fe38ff3eb16e32de9416e9bf1c2445e863eb6' "$archive" | sha256sum -c - || exit 1
tar -tzf "$archive" > "$work/archive.list" || exit 1
if grep -qE '(^/|(^|/)\.\.(/|$))' "$work/archive.list"; then
  echo 'Unsafe path found in source archive' >&2
  exit 1
fi
tar -xzf "$archive" -C "$work" || exit 1
bash "$work/ternux-1.4.0/install.sh"
printf 'Resume দরকার হলে এই directory রাখুন: %s\n' "$work"
```

Installer শেষ না হওয়া পর্যন্ত Termux session চালু রাখুন। আবশ্যক ধাপে ব্যর্থ
হলে একই extract করা `ternux-1.4.0` directory থেকে আবার চালান; retry করতে guest
মুছবেন না। Install শেষ হলে `printf`-এ দেখা temporary directory-টিই সরান, তবে
আগে path যাচাই করুন। Archive tag-এ pin করা; এর library `main` থেকে আসে না।

## Version যাচাই

Install-এর আগে tagged installer-এ নিচের output দেখুন:

```text

```

Install-এর পরে নতুন Termux shell-এ চালান:


প্রথম command-এ `1.4.0` থাকা উচিত। `x` দিয়ে desktop চালিয়ে
`ternux verify` এবং guest-এর ভেতরে `glxinfo -B` দেখুন। Renderer শনাক্ত হওয়া
performance বা সব device-এ qualification প্রমাণ করে না।

## সমস্যা ও recovery

- **`curl` চালু হয় না:** command `wget` চেষ্টা করে। দুটোই ব্যর্থ হলে Termux
  package/network ঠিক করে একই tag URL আবার চেষ্টা করুন।
- **Checksum মেলে না:** থামুন; archive extract বা চালাবেন না। আবার download
  করে tag commit যাচাই করুন।
- **Storage কম বা install থেমেছে:** guest না মুছে জায়গা খালি করুন; install
  state-এ `--resume` থাকলে ব্যবহার করুন, নইলে একই install command আবার চালান।
- **Desktop দেখা যায় না:** Termux:X11 খুলে Termux-এ ফিরে `source ~/.bashrc`
  এবং `x` চালান। Tag archive-এর troubleshooting guide দেখুন।
- **Upgrade:** পরের release-এর নিজস্ব guide ব্যবহার করুন; v1.4.0 installer-কে
  moving branch-এ point করবেন না।
