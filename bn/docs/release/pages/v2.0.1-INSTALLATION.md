**সংস্করণ:** Ternux v2.0.1<br>
**Tag:** `v2.0.1`<br>
**Stable APT:** প্রত্যাহৃত; এই নির্দেশিকা APT ব্যবহার করে না।

এই পদ্ধতি শুধু `v2.0.1` tag-এ প্রকাশিত source archive বসায়। এটি কখনো `main`,
চলমান branch বা অন্য release থেকে code নামায় না। v2.0.1 release page-এ নির্দিষ্ট archive ও `SHA256SUMS` file আছে। যেকোনো
asset না থাকলে অন্য source ব্যবহার না করে থামুন।

## প্রয়োজনীয়তা

- ARM64 Android-এ F-Droid অথবা Termux-এর official GitHub release থেকে Termux।
- অফিসিয়াল Termux:X11 বসিয়ে একবার খুলুন।
- অফিসিয়াল source থেকে Termux:X11 install করতে Android-এর অনুমতি দিন। Shared
  storage permission ঐচ্ছিক; শুধু shared storage দরকার এমন feature ব্যবহার করলে দিন।
- Base desktop-এর জন্য অন্তত ৫ GB খালি জায়গা এবং download/cache-এর জন্য অতিরিক্ত
  জায়গা।
- কাজ করা Termux package source ও network। Archive installer-এর জন্য `curl`
  অথবা `wget`, `tar`, এবং `bash` লাগবে।
- Termux add-on একই distribution source থেকে বসান। Camera/microphone integration
  ছাড়া Termux:API ঐচ্ছিক।

## নির্দিষ্ট সংস্করণ বসানো

Termux-এ এই version-pinned release asset URL ব্যবহার করুন। এগুলো কখনো `main`
branch-এ বদলাবেন না:

```bash
pkg update -y
pkg install -y bash ca-certificates coreutils curl grep tar wget
work="$(mktemp -d)" || exit 1
archive="$work/ternux-v2.0.1-source.tar.gz"
checksums="$work/SHA256SUMS"
base_url="https://github.com/soobujmiah/ternux/releases/download/v2.0.1"
for item in "ternux-v2.0.1-source.tar.gz" "SHA256SUMS"; do
  if ! curl -fL "$base_url/$item" -o "$work/$item"; then
    wget -O "$work/$item" "$base_url/$item" || exit 1
  fi
done
cd "$work" || exit 1
grep -F '  ternux-v2.0.1-source.tar.gz' "$checksums" | sha256sum -c - || exit 1
tar -tzf "$archive" > "$work/archive.list" || exit 1
if grep -qE '(^/|(^|/)\.\.(/|$))' "$work/archive.list"; then
  echo 'Unsafe path found in source archive' >&2
  exit 1
fi
grep -qx 'ternux-2.0.1/install.sh' "$work/archive.list" || exit 1
tar -xzf "$archive" -C "$work" || exit 1
bash "$work/ternux-2.0.1/install.sh"
printf 'Resume দরকার হলে এই directory রাখুন: %s\n' "$work"
```

প্রকাশিত `SHA256SUMS` file-এ এই archive-এর checksum entry থাকতে হবে। অন্তর্ভুক্ত
`install.sh` release-এর সঙ্গে থাকা library ব্যবহার করে, `main` থেকে library আনে না।

## যাচাই

ইনস্টল শেষে `ternux --version`-এ `2.0.1` দেখা উচিত। `ternux verify` ও
`ternux doctor --quick` চালিয়ে guest শুরু করুন; guest-এর ভেতরে `glxinfo -B`
দেখুন। নির্দিষ্ট guest যাচাইয়ে `tx verify debian`, `tx verify ubuntu`,
`tx verify kali`, অথবা `tx verify alpine` ব্যবহার করুন।

v2-এর owner-confirmed verified desktop baseline হলো Debian, Ubuntu, Kali Linux
ও Alpine Linux। প্রমাণ device ও feature-নির্দিষ্ট; feature matrix দেখুন। অন্য
নামযুক্ত recipe ও generic OCI guest এই support দাবির অংশ নয়।

## Recovery, সীমাবদ্ধতা ও নিরাপত্তা

পুরনো source installation update করতে `ternux update` চালান। এটি latest stable
release tag খুঁজে exact commit ও staged CLI/module tree যাচাই করে; validation
ব্যর্থ হলে আগের CLI ফিরিয়ে দেয়। এতে Ternux CLI update হয়; guest package update
আলাদা। Install মাঝপথে থামলে guest রেখে একই release installer আবার চালিয়ে
resume করুন। `ternux repair` চালানোর আগে `ternux doctor` ও তার log path দেখুন।
প্রত্যাহৃত stable APT ব্যবহার করবেন না, এবং v2 guest-এর ওপর v1.4.0 installer
চালাবেন না; updater নতুন version-কে পুরনো stable release-এ downgrade করে না।

v2 হলো no-root PRoot desktop; kernel container, systemd বা Android process
scheduling নিয়ন্ত্রণ দেয় না। GPU/graphics দাবি নথিভুক্ত device/configuration-এ
সীমিত। HTP/HMX ও QNN পরীক্ষামূলক; AI preview মানেই সব model/device support নয়।
Camera integration হলো Termux:API দিয়ে still photo, continuous webcam stream
নয়। Install-এর আগে প্রকাশিত checksum, source commit, সীমাবদ্ধতা ও security
policy যাচাই করুন।
