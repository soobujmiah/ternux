01ইনস্টল

একই বিশ্বস্ত উৎস থেকে Termux ও Termux:X11 install করুন, Termux:X11 একবার খুলুন, তারপর Termux-এ installer চালান।

# Termux-এ
curl -fsSL https://soobujmiah.github.io/ternux/install.sh | bash

curl না থাকলে wget ব্যবহার করুন:

wget -qO- https://soobujmiah.github.io/ternux/install.sh | bash

বেস install-এ প্রায় ৩–৪ GB লাগে। Download ও cache-এর জন্য অতিরিক্ত জায়গা রাখুন। Interactive terminal-এ optional workload সংখ্যা দিয়ে বেছে নিন; শুধু বেস desktop চাইলে Enter চাপুন। Prompt ছাড়া base install-এর জন্য --yes দিন।

Termux-এ desktop চালু করে Termux:X11 app-এ যান।

source ~/.bashrc

ternux status

সমস্যা মেরামত

ternux repair

Driver বা package বদলালে সাধারণ setup সমস্যা আবার ঠিক করুন।

Debian shell

db

Termux-এ `db` চালান। Debian-এর ভেতরে Android shared storage পাবেন `/sdcard`-এ।

`x` desktop চালায়। `xgo` Termux:X11 খুলে desktop চালায়।

03এই workstation-এ কী করা যায়

Ternux ARM64 ফোনকে বাস্তব project-এর Linux workspace করে। নিচের উদাহরণগুলো প্রতিষ্ঠিত Redmi workstation-এর; অন্য device-এ graphics ও গতি আলাদা হতে পারে।

Linux-এ development

Debian desktop, terminal, editor, Git, Python ও Node.js দিয়ে দৈনন্দিন কাজ করুন। Compiler ও build tool লাগলে setup-এর সময় development workload নিন।

3D ও animation

Blender-এর EEVEE Next ব্যবহার করা যায়। প্রতিষ্ঠিত Adreno setup-এ headless render-এর জন্য Xvfb এবং Zink/Turnip GPU offload লাগে। ওই workstation-এ EEVEE render মাপা হয়েছে; Cycles GPU এখনো qualified নয়। Local MCP দিয়ে coding agent GPU route যাচাই করে একই setup-এ script বা scene render করতে পারে।

লোকাল language model

লক্ষ্য device-এ llama.cpp CPU + Vulkan package চালানো হয়েছে। Model আলাদা এবং shared memory যথেষ্ট হতে হবে। HTP পরীক্ষামূলক; Stable Diffusion.cpp inference এখনো পরীক্ষা করা হয়নি।

মাপা ফল ও সীমা →

Media তৈরি ও সম্পাদনা

ভিডিও রূপান্তর, ছবি সম্পাদনা, audio কাজ ও batch processing-এর জন্য FFmpeg, GIMP, Audacity ও ImageMagick যোগ করুন। এগুলো install করা যায়; গতি device অনুযায়ী বদলায়।

Android app development

একই Termux + PRoot workstation-এ ADT-ও চলে। Flutter/Gradle build, APK install ও physical-device validation ADT workflow হিসেবে verified; Ternux desktop session-এর ভেতর থেকে ADT চালানো এখনো আনুষ্ঠানিকভাবে পরীক্ষা করা হয়নি।

Interactive install-এর সময় সংখ্যা দিয়ে optional workload বেছে নিন। সবগুলো install-এ প্রায় ১০–১২ GB installed space-এর পাশাপাশি download ও build-এর অস্থায়ী জায়গা লাগবে; দরকারি workload-গুলোই নিন।
