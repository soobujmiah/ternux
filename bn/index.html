ধাপ ২

এক-কমান্ড ইনস্টলার চালান

Termux খুলে পেস্ট করুন। ইনস্টলার GPU শনাক্ত করে, বেস প্যাকেজ ইনস্টল করে, Debian + Xfce4 তৈরি করে, গ্রাফিক্স পথ সাজায়, লঞ্চার লেখে এবং সব যাচাই করে (১১টি ধাপ)।

$ curl -fsSL https://soobujmiah.github.io/ternux/install.sh | bash

চালানোর আগে সব source দেখতে চান? Repository clone করুন, যাতে entry script ও তার ব্যবহৃত সব module স্থানীয় থাকে:

$ pkg install git -y $ git clone https://github.com/soobujmiah/ternux.git && cd ternux $ git log -1 --oneline $ (set -e; for f in install.sh uninstall.sh bin/ternux lib/*.sh; do bash -n "$f"; done) $ less install.sh bin/ternux lib/*.sh $ bash install.sh

বিঘ্নিত হলে --resume দিয়ে চালান; শুধু সফল হিসেবে রেকর্ড হওয়া ধাপগুলো বাদ যাবে। স্থানীয়ভাবে চালালে পরিবর্তনের আগে একবার নিশ্চিত করতে বলে, পাইপ করা রুটটি অনুপস্থিতিতে চলে।

পরিচালনা

ternux CLI — স্থায়ী ব্যবস্থাপনা ইন্টারফেস

ইনস্টলের পর ternux CLI ব্যবহার করুন সবকিছুর জন্য:

$ ternux doctor # সিস্টেম ডায়াগনস্টিক $ ternux doctor --json # machine-readable output $ ternux start # ডেস্কটপ চালু $ ternux stop # ডেস্কটপ বন্ধ $ ternux repair # সাধারণ সমস্যা সমাধান $ ternux verify # ইনস্টলেশন যাচাই $ ternux backend set virgl # GPU ব্যাকএন্ড পরিবর্তন $ ternux update # CLI আপডেট $ ternux info --json # মেশিন-পাঠযোগ্য তথ্য $ ternux uninstall # কম্পোনেন্ট অপসারণ

ডিসপ্যাচার global flag শনাক্ত করে; JSON output কমান্ডভেদে আলাদা। সমর্থিত schema-এর জন্য CLI রেফারেন্স দেখুন।

প্রথম ধাপ

আপনার ফোন কোন গ্রাফিক্স পাথে চলবে?

Qualcomm Adreno — সরাসরি পথ

ls /dev/kgsl-3d0 চালালে ফাইলটি পেলে আপনার GPU Adreno। ইনস্টলার স্বয়ংক্রিয়ভাবে Zink বেছে নেয়: OpenGL → Vulkan → Turnip → driver ওই device সমর্থন করলে hardware; অনুমান না করে renderer যাচাই করুন।

পরীক্ষিত Adreno পথrenderer দিয়ে যাচাই করুন

যে ফাঁদে পড়ার ভয়: Turnip প্যাকেজে Vulkan লোডার থাকে না। libvulkan1 না থাকলে Zink নিঃশব্দে CPU রেন্ডারিংয়ে নেমে যায় — কোনো এরর মেসেজ ছাড়াই। ইনস্টলার লোডার, ICD ও ড্রাইভার তিনটিই ইনস্টল করে যাচাই করে।

Mali, Xclipse, PowerVR — সামঞ্জস্যপূর্ণ পথ

/dev/kgsl-3d0 না থাকলে Turnip চলবে না। ইনস্টলার VirGL বেছে নেয় — GL কমান্ড Termux পাশের একটি helper process-এ যায়। Feature coverage, acceleration ও গতি ডিভাইসভেদে বদলায়; renderer ও workload যাচাই করুন।

সামঞ্জস্যের সম্ভাব্য পথডিভাইসভেদে আলাদা

মনে রাখুন: Mali GPU-কে Turnip পথে নেওয়া অসম্ভব। সঠিকভাবে VirGL বেছে নেওয়াই এখানে আসল জয়।

ডিজাইন সিদ্ধান্ত

ternux যেভাবে কাজ করে, তার কারণ

কেন root নয়?

Root-based change verified boot-এ প্রভাব ফেলতে ও blast radius বাড়াতে পারে। PRoot Android root ছাড়াই root-like filesystem emulate করে, তবে এটি security boundary নয়—Termux-accessible path reachable থাকে। Scoped uninstaller ব্যবহার করুন এবং আগে Debian container backup নিন।

কেন Zink + Turnip?

সমর্থিত Adreno ডিভাইসে Android সাধারণ desktop OpenGL stack-এর বদলে Vulkan/KGSL দেয়। Zink GL-কে Vulkan-এ অনুবাদ করে এবং Turnip GPU চালায়; সফল launch দেখেই acceleration ধরে না নিয়ে renderer evidence দিয়ে route নিশ্চিত করুন।

কেন যাচাইকৃত ধাপ?

দৃশ্যমান ডেস্কটপ সফলতার প্রমাণ নয় — সফটওয়্যার রেন্ডারিং Blender চালানো পর্যন্ত ঠিকই দেখায়। প্রতিটি ধাপ পরেরটির আগে নিজের কাজ যাচাই করে, তাই ব্যর্থতা জোরে, শুরুতেই আসে। Resume বিঘ্নিত install চালায়; ternux repair সমর্থিত targeted fix প্রয়োগ করে।

কেন পর্যালোচনাযোগ্য source?

MIT-লাইসেন্সকৃত bootstrap ও library module চালানোর আগে download করে পড়া যায়। Code, package ও driver asset-এর GitHub, Termux/Debian এবং Mesa source নথিতে চিহ্নিত; one-command route সুবিধার বিনিময়ে কিছু review সুযোগ কমায়।
