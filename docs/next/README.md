This is the entry point for future work. The material here is exploratory and
must not be read as a commitment, a supported feature list, or evidence that a
package channel is available. The project continues to maintain four desktop
setups: Debian, Ubuntu, Kali Linux, and Alpine. The Termux package repository
is currently unavailable.

## Planning documents

- [Implementation roadmap](IMPLEMENTATION-ROADMAP.html): staged work, evidence
  requirements, and decision points.
- [Architecture and proposals](../NEXT-ARCHITECTURE.html): possible future
  components and boundaries.
- [Detailed architecture index](architecture/README.html): manager, workspace,
  device bridge, security, and acceptance design notes.
- [Feature proposals](../NEXT-PROPOSALS.html): ideas requiring feasibility and
  owner review.
- [Distribution feasibility](APT-DISTRIBUTION-FEASIBILITY.html): package
  channel considerations; it does not claim an installable channel.
- [Manager API schemas](https://github.com/soobujmiah/ternux/tree/main/docs/next/schemas):
  machine-readable contracts used by source tests.

Historical release records remain available for provenance and dated evidence;
they do not define current support. The [current project roadmap](../project/PROJECT-ROADMAP.html)
and [support matrix](https://github.com/soobujmiah/ternux/blob/main/docs/audit/FEATURE-MATRIX.md) describe present status.
