## Priorities

1. Keep release, installation, and package-channel statements aligned with
   available evidence. The current APT/package channel is unavailable; do not
   advertise `pkg install ternux`.
2. Preserve APT timeout/dpkg recovery behavior and continue running its
   regression tests.
3. Keep Debian, Ubuntu, Kali Linux, and Alpine setup recipes documented while
   clearly distinguishing them from physical-device qualification.
4. Review Next Version proposals in small, testable slices; do not imply a
   proposal is shipped or a release commitment.
5. Keep English and Bengali user-facing guidance aligned and check links/builds
   after documentation edits.

For current state see [release status](RELEASE-STATUS.md),
[implementation status](IMPLEMENTATION-STATUS.md), and
[known limitations](KNOWN-LIMITATIONS.md). Preserve dated release evidence in
the [release archive](../release/README.md).
