**Release:** Ternux v2.0.1<br>
**Tag:** `v2.0.1`<br>
**Stable APT:** withdrawn; this guide does not configure or use APT.

This procedure installs only the source archive published with tag `v2.0.1`.
It never downloads code from `main`, a moving branch, or a different release.
The v2.0.1 release page provides the named archive and its `SHA256SUMS` file.
If either asset is unavailable, stop instead of substituting another source.

## Requirements

- ARM64 Android with Termux from F-Droid or official Termux GitHub releases.
- Termux:X11 installed from the official project and opened once.
- Allow Android to install the Termux:X11 app from its official source. Shared
  storage permission is optional; grant it only if you use a feature that needs
  Android shared storage.
- At least 5 GB free for a base desktop; keep additional room for package
  downloads and caches.
- Working Termux package sources and network access. `curl` or `wget`, `tar`,
  and `bash` are needed for the source archive installer.
- Install Termux add-ons from the same distribution source. Termux:API is
  optional and is needed only for camera/microphone integrations.

## Exact-version installation

Use these version-pinned release asset URLs from Termux. They must never be
changed to use `main`:

```bash
pkg update -y
pkg install -y bash ca-certificates coreutils curl grep tar wget
work="$(mktemp -d)" || exit 1
archive="$work/ternux-v2.0.1-source.tar.gz"
checksums="$work/SHA256SUMS"
base_url="https://github.com/soobujmiah/ternux/releases/download/v2.0.1"
for item in "ternux-v2.0.1-source.tar.gz" "SHA256SUMS"; do
  if ! curl -fL "$base_url/$item" -o "$work/$item"; then
    wget -O "$work/$item" "$base_url/$item" || exit 1
  fi
done
cd "$work" || exit 1
grep -F '  ternux-v2.0.1-source.tar.gz' "$checksums" | sha256sum -c - || exit 1
tar -tzf "$archive" > "$work/archive.list" || exit 1
if grep -qE '(^/|(^|/)\.\.(/|$))' "$work/archive.list"; then
  echo 'Unsafe path found in source archive' >&2
  exit 1
fi
grep -qx 'ternux-2.0.1/install.sh' "$work/archive.list" || exit 1
tar -xzf "$archive" -C "$work" || exit 1
bash "$work/ternux-2.0.1/install.sh"
printf 'Keep this directory if you need to resume: %s\n' "$work"
```

The published `SHA256SUMS` must contain the checksum entry for this archive.
The included `install.sh` uses the release's bundled libraries and does not
fetch them from `main`.

## Verify

After installation, `ternux --version` must print `2.0.1`. Run
`ternux verify` and `ternux doctor --quick`; then start the selected guest and
check `glxinfo -B` inside it. For a specific guest, use `tx verify debian`,
`tx verify ubuntu`, `tx verify kali`, or `tx verify alpine`.

The v2 verified desktop baseline is Debian, Ubuntu, Kali Linux, and Alpine
Linux. The evidence is device- and feature-bounded; see the feature matrix.
Other named recipes and generic OCI guests are not included in this support
claim.

## Recovery, limitations, and security

To update an existing source installation, run `ternux update`. It resolves the
latest stable release tag, verifies the exact commit and staged CLI/module tree,
and restores the previous CLI if validation fails. This updates the Ternux CLI;
guest package updates remain separate. If installation is interrupted, keep the
guest and rerun the same release installer to resume. Use `ternux doctor` and
its reported log path before `ternux repair`. Do not use the withdrawn stable
APT route or run the v1.4.0 installer over an existing v2 guest; the updater
does not downgrade a newer version to an older stable release.

The v2 release is a no-root PRoot desktop and cannot provide kernel containers,
systemd, or control over Android process scheduling. GPU/graphics qualification
is limited to recorded devices and configurations. HTP/HMX and QNN remain
experimental; optional AI workload previews do not imply broad model or device
support. Camera integration is still-photo capture through Termux:API, not a
continuous webcam stream. See the release's published checksums, source commit,
limitations, and security policy before installation.
