02 · Architecture

Clear boundaries. Explicit data paths.

ternux does not replace Android. It composes a userspace Linux environment around Android services and exposes the selected backend instead of hiding it.

Adreno route, with a fallback

Supported Adreno devices can use Zink/Turnip. VirGL remains the public compatibility route. A working desktop alone is not proof that hardware rendering is active.

✓

No Android root. No hidden boundary.

ternux does not modify the Android system partition. Guest root exists inside PRoot and is not a security boundary; shared storage and services you expose remain your responsibility.
