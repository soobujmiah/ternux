01Install

Install Termux and Termux:X11 from compatible sources, open Termux:X11 once, then run the installer in Termux.

# in Termux
curl -fsSL https://soobujmiah.github.io/ternux/install.sh | bash

If curl is unavailable, use wget:

wget -qO- https://soobujmiah.github.io/ternux/install.sh | bash

The base install uses about 3–4 GB. Keep extra space for downloads and caches. With a terminal attached, choose optional workloads by number: 1 development, 2 llama.cpp, 3 network, 4 media, 5 Blender, 6 all; press Enter or 0 for base only. Use --yes for unattended base install.

03What you can do here

Ternux turns this ARM64 phone into a Linux workspace for real projects. The examples below reflect the established Redmi workstation; graphics and performance still depend on your device.

Build and work in Linux

Use a Debian desktop, terminal, editors, Git, Python and Node.js for everyday development. Add the development workload during setup when you need compilers and build tools.

Make 3D scenes and animation

Blender is available with EEVEE Next. On the established Adreno setup, headless renders use Xvfb and GPU offload through Zink/Turnip. EEVEE rendering is measured on that workstation; Cycles GPU is not qualified. A local MCP lets coding agents check the GPU route and render scripts or scenes with the same setup.

Run local language models

The llama.cpp CPU + Vulkan package has been exercised on the target device. Model files are separate and need enough shared memory. HTP is experimental; Stable Diffusion.cpp inference is not yet tested.

Measured results and limits →

Create and edit media

Add FFmpeg, GIMP, Audacity and ImageMagick for video conversion, image work, audio editing and batch processing. These are installable Linux tools; speed varies by device.

Develop Android apps

The same Termux + PRoot workstation also hosts ADT. Its Flutter/Gradle build, APK install and physical-device validation are verified as an ADT workflow; using ADT directly inside a Ternux desktop session is not yet formally tested.
